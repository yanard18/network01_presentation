DNS Çözümleme Sırası

1. OS Cache ➔ 2. /etc/hosts ➔ 3. Local DNS ➔ 4. Public DNS
1. OS & Tarayıcı Cache: Tarayıcı ve işletim sistemi önbelleğindeki kayıtları kontrol eder.
2. Hosts Dosyası (/etc/hosts): Yerel statik IP-domain eşleşmelerini kontrol eder.
3. Yerel DNS Sunucusu: Ağdaki lokal DNS sunucusuna (router / kurumsal DNS) sorgu gönderir.
4. Kamu (Public) DNS Hiyerarşisi: Kayıt yerelde yoksa küresel sunuculara (Root ➔ TLD ➔ Authoritative) başvurur.
5. Sonuç: Bulunursa IP adresi döndürülür, bulunamazsa NXDOMAIN hatası verilir.
