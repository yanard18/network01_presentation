DNS Çözümleme (Resolution) Sırası

1. OS Cache (Önbellek) ➔ 2. /etc/hosts ➔ 3. Dahili (Internal) DNS ➔ 4. Harici (External) / ISP
1. OS & Tarayıcı (Browser) Cache: Anında Bellek (Memory) Taraması. Yerel RAM'i (systemd-resolved, tarayıcı önbelleği) kontrol eder. Bulunursa IP'yi hemen döndürür.
2. Statik Dosyalar (/etc/hosts): Sıfır Ağ Trafiği. /etc/nsswitch.conf (hosts: files dns) tarafından yönetilir. Domain eşleşmeleri (mappings) için yerel statik dosyayı inceler (ör. 10.10.11.23 target.htb).
3. Dahili (Internal) DNS Sunucusu: Yerel Ağ Sorgusu (UDP 53). İstemci (Client), yerel ağ bölgelerini (zones) kontrol etmek için yerel router/kurumsal DNS'e (192.168.1.1 veya 10.0.0.2) recursive sorgu gönderir.
4. Harici (External) / ISP DNS Yönlendirmesi (Forwarding): Upstream Küresel Tarama. Domain halka açık (public) ise (ör. google.com), Dahili DNS sorguyu ISP / Public DNS'e (8.8.8.8) yönlendirerek (forwards) Root ➔ TLD ➔ Authoritative iteratif taramasını gerçekleştirir.
5. Çözümlenemeyen (Unresolved) Domain İşlemi: NXDOMAIN Hatası. Hiçbir sunucuda kayıt (record) yoksa, Authoritative sunucu NXDOMAIN (Mevcut Olmayan Domain) döndürerek geriye doğru yayılır ve ekranda ERR_NAME_NOT_RESOLVED gösterilmesini sağlar.
