1 Single TCP Socket & Binary Streams

Unlike HTTP/1.x, HTTP/2 breaks requests into binary frames and multiplexes multiple bidirectional streams concurrently over 1 single TCP connection.
CLIENT (Port 51234) 1 SINGLE TCP CONNECTION (TLS 1.2/1.3) SERVER (Port 443)
Stream 1 (HTML)
HEADERS Frame (0x01) DATA Frame (0x00)
Stream 3 (CSS)
HEADERS Frame (0x01) DATA Frame (0x00)
Stream 5 (JS App)
HEADERS Frame (0x01) DATA Frame (0x00)
Binary Frame Header Structure (9 Bytes): Length (24b) | Type (8b) | Flags (8b) | Stream ID (31b) | Payload Data...
HTTP/2 Advantage: Replaces 6 separate TCP handshakes with 1 single TCP connection and compresses headers using HPACK algorithm.
