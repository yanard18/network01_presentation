SMB 1.0 (Legacy & Threats)

DIALECT CODE: 0x0000 / LEGACY
SECURITY THREAT Critical Architectural Vulnerabilities
  • Null Sessions: Allowed unauthenticated users to enumerate domain accounts, shares, and policies.
  • Famous Exploits: Primary vector for EternalBlue (MS17-010), WannaCry, and NotPetya.
  • Deprecation: Officially disabled and deprecated across all modern operating systems.
Cybersecurity Status: Hard-disabled by default in Windows 10/11 & Server 2019+.
