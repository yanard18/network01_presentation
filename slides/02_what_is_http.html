What is HTTP?

CORE DEFINITION Application Layer Protocol
  • HTTP is an application layer protocol for transmitting hypermedia documents.
  • Designed for communication between web browsers and web servers.
  • Also heavily used in APIs and machine-to-machine communication.
  • Uses TCP or TLS-encrypted TCP as its transport mechanism.
  • Transmits hypertext documents structured with hyperlinks via a Client-Server model.
