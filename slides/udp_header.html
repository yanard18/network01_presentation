The UDP Header

Figure: Lightweight UDP Header Format (Fixed 8 Bytes)
UDP FIELDS Brief Field Breakdown
  • Source Port (16 Bits): Port of sending application process (optional; set to 0 if no reply expected).
  • Destination Port (16 Bits): Target application process port on destination host.
  • Length (16 Bits): Total size of UDP header plus application data in bytes (minimum value = 8).
  • Checksum (16 Bits): Error detection covering header, payload, and pseudo-IP header.
