HTTP Headers Reference

HTTP Headers are key-value pairs (e.g. Header-Name: Value) sent in requests and responses to exchange metadata.
REQUEST HEADERS

Sent by the client to provide context about the request, client environment, or credentials:

  • Host: target.htb (Mandatory in HTTP/1.1)
  • User-Agent: Client browser/tool signature
  • Authorization: Bearer <token> / Basic
  • Accept: application/json, text/html
RESPONSE HEADERS

Sent by the server to provide additional information about the response or server setup:

  • Server: Apache/2.4.50 (Unix)
  • Set-Cookie: session=xyz123; Secure
  • Location: /login.php (3xx Redirects)
  • Access-Control-Allow-Origin: CORS
REPRESENTATION HEADERS

Describes the format, size, and encoding of the message payload body:

  • Content-Type: application/json
  • Content-Length: 4096 (Payload size in B)
  • Content-Encoding: gzip / br (Compression)
CONTROL & CACHING

Manages connection state and browser caching behaviors:

  • Cache-Control: no-cache, max-age=3600
  • Connection: keep-alive / close
  • Strict-Transport-Security: HSTS
