HTTP Headers Referansı

HTTP Headers (Başlıklar), request (istek) ve response'larda (yanıt) metadata alışverişi yapmak için gönderilen anahtar-değer (key-value) çiftleridir (ör. Header-Name: Value).
REQUEST HEADERS

İstek, istemci (client) ortamı veya credential bilgileri hakkında bağlam (context) sağlamak için client tarafından gönderilir:

  • Host: target.htb (HTTP/1.1'de Zorunludur)
  • User-Agent: Client browser/tool imzası
  • Authorization: Bearer <token> / Basic
  • Accept: application/json, text/html
RESPONSE HEADERS

Yanıt (response) veya sunucu yapılandırması (server setup) hakkında ek bilgiler sağlamak için sunucu (server) tarafından gönderilir:

  • Server: Apache/2.4.50 (Unix)
  • Set-Cookie: session=xyz123; Secure
  • Location: /login.php (3xx Redirect)
  • Access-Control-Allow-Origin: CORS
REPRESENTATION HEADERS

Message payload gövdesinin formatını, boyutunu ve kodlamasını (encoding) açıklar:

  • Content-Type: application/json
  • Content-Length: 4096 (Byte cinsinden payload boyutu)
  • Content-Encoding: gzip / br (Compression)
CONTROL & CACHING

Bağlantı durumunu (connection state) ve tarayıcı cache davranışlarını yönetir:

  • Cache-Control: no-cache, max-age=3600
  • Connection: keep-alive / close
  • Strict-Transport-Security: HSTS
