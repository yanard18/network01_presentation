TCP Header Structure

Figure: TCP Header Format (20 to 60 Bytes)
HEADER FIELDS Key Explanations
  • Source & Dest Ports (16b): Identify originating and receiving application processes.
  • Sequence Number (32b): Tracks byte ordering and detects missing bytes in data stream.
  • Acknowledgment Number (32b): Specifies next expected byte from remote host for reliability.
  • Data Offset (4b): Specifies total TCP header length in 32-bit words.
  • Control Flags (9b): Session management bits (SYN, ACK, FIN, RST, PSH, URG).
  • Window Size (16b): Flow control buffer space advertised by receiver.
  • Checksum (16b): Ensures bit-level integrity of header and payload.
Minimum size: 20 bytes (no options). Max: 60 bytes.
