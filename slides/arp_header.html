ARP Başlık (Header) Yapısı

Şekil: ARP Paketi Başlık Yapısı (IPv4 over Ethernet için 28 Byte)
ARP ALANLARI Temel Açıklamalar
  • Hardware & Protocol Type (4B): Ethernet (1) ve IPv4 (0x0800) tanımı.
  • Hardware & Protocol Size (2B): MAC (6B) ve IP (4B) adres uzunlukları.
  • Opcode (2B): İşlem türü (1 = İstek/Request, 2 = Yanıt/Reply).
  • Sender Addresses (10B): Gönderen MAC (6B) ve IP (4B) adresleri.
  • Target Addresses (10B): Hedef MAC (6B) ve IP (4B) adresleri.
IPv4'ten Ethernet'e çözümleme için 28 byte paket yapısı.
