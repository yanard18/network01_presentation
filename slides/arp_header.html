ARP Başlık (Header) Yapısı

Şekil: ARP Paketi Başlık Yapısı (IPv4 over Ethernet için 28 Byte)
ARP ALANLARI Kısa Alan Dağılımı (Field Breakdown)
  • Donanım Türü (Hardware Type - 2B): Ağ protokolü türü (ör. Ethernet için 1).
  • Protokol Türü (Protocol Type - 2B): Üst protokol türü (ör. IPv4 için 0x0800).
  • Donanım Boyutu (Hardware Size - 1B): Bayt cinsinden MAC adresi uzunluğu (Ethernet için 6).
  • Protokol Boyutu (Protocol Size - 1B): Bayt cinsinden IP adresi uzunluğu (IPv4 için 4).
  • İşlem Kodu (Opcode - 2B): İşlem kodu (İstek/Request için 1, Yanıt/Reply için 2).
  • Gönderici (Sender) / Hedef (Target) Adresleri: Gönderici MAC (6B) & IP (4B), Hedef MAC (6B) & IP (4B).
IPv4'ten Ethernet'e çözümleme (resolution) için sabit 28 byte'lık paket yapısı.
