Credential Testing & State Machine

Credential testing (brute-forcing or validating user passwords) takes place purely during the Session Setup phase of the SMB state machine.
STEP 1
TCP Handshake

Client establishes raw TCP connection to Port 445.

STEP 2
SMB Negotiate

Client & Server agree on SMB dialect (e.g. SMB 2.1 / 3.1.1).

STEP 3
Session Setup

Sends NTLM or Kerberos auth wrapped in SPNEGO payload.

STEP 4
Auth Response

Returns STATUS_SUCCESS or LOGON_FAILURE response.

root@htb:~# nmap --script smb-brute -p 445 target.htb 
| smb-brute:
|   Accounts:
|     administrator:Password123! => Valid Credentials (STATUS_SUCCESS)
|_    guest:guest => Account Disabled (STATUS_ACCOUNT_DISABLED)
