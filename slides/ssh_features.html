SSH Temel Özellikleri (Key Features)

AUTHENTICATION

Şifrelenmiş (encrypted) parola girişlerini (password logins) ve güvenli Public Key Authentication yöntemlerini (ör. Ed25519 ve RSA anahtarları) destekler.

SHELL COMMANDS & OUTPUT

Tüm interaktif terminal tuş vuruşları (keystrokes), uzak komutlar (remote commands) ve sunucu yanıtları simetrik şifreleme (symmetric ciphers, ör. AES-256-GCM) ile korunur.

SECURE FILE TRANSFERS

Entegre güvenli dosya transfer protokolleri — SFTP (SSH File Transfer Protocol) ve SCP — doğrudan port 22 üzerinden çalışır.

INTEGRITY & PORT FORWARDING

Verilerin manipüle edilmesini (tampering) önlemek için kriptografik HMAC'ler kullanır ve SSH Port Forwarding (Local, Remote, ve Dinamik SOCKS Tünelleri) desteği sağlar.
