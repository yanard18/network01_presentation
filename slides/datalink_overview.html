Data Link Layer (Veri Bağı Katmanı) Genel Bakış

Çerçeveleme (Framing) & Adresleme

Layer 3 IP paketlerini fiziksel MAC adreslerine sahip frame'lere (çerçevelere) kapsüller (encapsulates).

Ortam İletimi (Medium Transmission)

Fiziksel katmanın veriyi ortam (kablo vb.) üzerinde elektriksel, optik veya radyo sinyallerine dönüştürebilmesi için frame'leri hazırlar.

Şekil: OSI Yığınında (Stack) Data Link Layer
