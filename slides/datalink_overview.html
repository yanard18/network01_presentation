Data Link Layer (Veri Bağı Katmanı) Genel Bakış

OSI LAYER 2 Doğrudan Node-to-Node (Düğümden Düğüme) İletişim

Bu derste, OSI modelinin Data Link Layer adı verilen 2. katmanını inceleyeceğiz. Temel görevi, fiziksel katmanda doğrudan birbirine bağlı olan iki cihaz arasında veriyi taşımaktır.

TEMEL GÖREVLER Birincil Sorumluluklar
Çerçeveleme (Framing) & Adresleme: Layer 3 IP paketlerini fiziksel MAC adreslerine sahip frame'lere (çerçevelere) kapsüller (encapsulates).
Ortam İletimi (Medium Transmission): Fiziksel katmanın veriyi ortam (kablo vb.) üzerinde elektriksel, optik veya radyo sinyallerine dönüştürebilmesi için frame'leri hazırlar.
Hata Tespiti (Error Detection) & Media Access Control (MAC)
Şekil: OSI Yığınında (Stack) Data Link Layer
