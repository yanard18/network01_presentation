MS-RPC Execution & Printing via SMB

REMOTE EXECUTION MS-RPC over SMB (ncacn_np)

Tools like PsExec and rpcclient execute commands remotely via Microsoft RPC (MS-RPC). MS-RPC uses SMB Named Pipes as its transport layer.

1. Open Named Pipe
SMB opens \pipe\srvsvc or \pipe\samr
2. Write RPC Request
SMB writes command execution payload
3. Read Execution Output
SMB reads result back from target service
Transport Binding: ncacn_np (Named Pipe Transport)
SPOOLER SERVICE Network Printing as File I/O

To the Windows Print Spooler Service, a network printer is simply an I/O destination (File Object).

  • When SMB is used for network printing, it opens a handle to the printer object.
  • SMB streams raw print job bytes to the printer destination.
  • To SMB, printing a document is identical to saving a .pdf file to a folder.
Printer Handle = I/O File Destination
