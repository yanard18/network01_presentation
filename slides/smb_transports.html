SMB Taşıma Protokolleri (Transports)

SMB 2 / SMB 3 protokol ailesi, farklı ağ senaryoları için 4 temel transport mekanizmasını destekler:
TCP 445 Direct TCP

Modern LAN dosya paylaşımı için güvenilir bağlantı yönelimli TCP üzerinde çalışan standart varsayılan taşıma katmanıdır.

Standard LAN Protocol Default
TCP 139 NetBIOS over TCP (NBT)

Eski işletim sistemleri ve NetBIOS name resolution için geriye dönük uyumluluk sağlayan legacy katmandır.

Legacy Backward Compatibility
SMB DIRECT RDMA Transport

Remote Direct Memory Access, veri merkezlerinde sıfır CPU yükü ile ultra düşük gecikmeli bellek transferine izin verir.

Datacenter & SAN Performance
UDP 443 SMB over QUIC

TLS 1.3 şifrelemesi ile UDP 443 üzerinden çalışarak VPN gerektirmeden internet üzerinden güvenli dosya erişimi sunar.

VPN-less Remote File Access
