IPV4 FIELDS Key Explanations
  • Version (4b): Identifies IP version (set to 4 for IPv4).
  • IHL (4b): Internet Header Length in 32-bit words (Min: 5 = 20B, Max: 15 = 60B).
  • Type of Service (8b): DSCP & ECN bits for Quality of Service (QoS) prioritization.
  • Ident & Flags (3b): Controls fragmentation (DF = Don't Fragment, MF = More Fragments).
  • Time-to-Live (TTL - 8b): Hop limit counter (default 64) decremented by routers to prevent loops.
  • Protocol (8b): Payload type ID (e.g. 6 = TCP, 17 = UDP, or IPv4-in-IPv4).
  • Header Checksum (16b): Validates header only integrity (removed in IPv6).
Variable header size due to optional IHL padding.
