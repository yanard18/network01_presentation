HTTP'nin 4 Temel Bloğu

Web ekosistemi dört temel yapı taşına dayanır:

BLOCK 1 Textual Format (HTML)

Hypertext belgeleri temsil etmek için kullanılan metinsel (textual) bir format: HyperText Markup Language (HTML).

BLOCK 2 Protocol (HTTP)

Bu belgeleri transfer etmek (exchange) için standartlaştırılmış iletişim protokolü: HTTP.

BLOCK 3 Client (Web Browser)

Belgeleri görüntülemek, yorumlamak (render) ve düzenlemek için kullanılan kullanıcı odaklı (user-facing) istemci uygulaması: Web Browser.

BLOCK 4 Server (httpd)

Depolanan hypermedia belgelerine erişim sağlayan (serve) bir sunucu servisi (daemon): httpd'nin erken sürümleri.
