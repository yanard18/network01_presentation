IP Routing Host'ta Başlar

İLK ROUTING KARARI Host, Veri Kabloya (Wire) İnmeden Önce Karar Verir!

PC1, Google'a (8.8.8.8) veri göndermek istiyor. PC1, 8.8.8.8'i kendi IP'si ve Mask'ı (10.1.1.50 / 255.255.255.0) ile karşılaştırır. Subnetting (alt ağ oluşturma) mantığını kullanarak, PC1 8.8.8.8'in kendi yerel LAN'ının dışında olduğunu belirler!

SENARYO A: AYNI SUBNET DIRECT ARP

Eğer hedef IP aynı yerel ağdaysa (local network), host hedef MAC adresini çözümlemek (resolve) için ARP kullanarak paketi doğrudan hedefe gönderir. Router'a gerek yoktur!

SENARYO B: FARKLI SUBNET DEFAULT GATEWAY

Hedef, yerel LAN'ın dışındadır → Host, paketi Default Gateway (Varsayılan Ağ Geçidi) Router'a (10.1.1.1) gönderir. Host, Ethernet Hedef (Destination) MAC = Router R1 MAC (CCC) olarak ayarlar!
