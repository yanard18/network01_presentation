SMB Bileşenleri (SMB Components)

SMB Server

Kaynakları (dosyalar, printer'lar ve named pipe'lar) paylaşan ve SMB Client'larından gelen isteklere yanıt veren bileşendir.

SMB Client

Uzak paylaşımlara bağlanan ve SMB Server'larına I/O istekleri gönderen bileşendir.

Hem Windows Server hem de Windows Client işletim sistemleri varsayılan olarak hem SMB Client hem de SMB Server bileşenlerini içerir.
