Flow Control & Sliding Window

Figure: TCP Dynamic Sliding Window Mechanism
FLOW CONTROL Preventing Buffer Overflow
  • Timing & Speed Mismatch: Fast senders transmitting to slow receivers cause memory buffer exhaustion and packet drops.
  • Advertised Window (rwnd): The receiver advertises its available buffer space in every ACK header (Window Size field).
  • Sliding Window Range: Limits how many unacknowledged bytes the sender can transmit at any moment.
  • Dynamic Window Slide: As receiver application reads data from buffer, the window slides forward, allowing new data transmission.
  • Zero Window (Pause): If receiver buffer fills up, it advertises Window = 0, ordering the sender to pause until space frees up.
Balances transmission rate directly with receiver processing capacity.
