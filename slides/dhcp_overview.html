Dynamic Host Configuration Protocol (DHCP)

DHCP (Layer 7), ağ cihazlarına IP adresleri, subnet mask'ları, varsayılan ağ geçitleri (default gateways) ve DNS sunucularını otomatik olarak sağlar (provisions).
MİMARİ (ARCHITECTURE) İstemci / Sunucu (Client/Server) Modeli

DHCP istemci/sunucu mimarisi kullanır. Ev router'ları gömülü (embedded) bir DHCP sunucusu barındırırken, DHCP istemci (client) daemon'ları tüm modern işletim sistemlerinde (OS) önceden yüklenmiş olarak gelir.

Merkezi IP Yönetimi (Administration)
YAPILANDIRMA (CONFIG) Dinamik vs. Statik

IP parametreleri manuel olarak atanabilir (statik) veya ağa katılırken DHCP aracılığıyla otomatik olarak dinamik şekilde tahsis edilebilir (allocated).

Zero-Touch Ağ Katılımı (Onboarding)
SÜRE (LIFETIME) DHCP Kira (Lease) Sistemi

DHCP sunucusu, cihazlara IP adreslerini belirli bir süre için (kira süresi / lease time) atayarak, adres havuzunun (address pool) kalıcı olarak tükenmesini (exhaustion) önler.

Dinamik Adres Havuzu Geri Dönüşümü (Recycling)
