Internet Protocol (IP)

Şekil: Network Layer (OSI Layer 3)
LAYER 3 Network Layer (Ağ Katmanı) Temeli

Bu bölümde, OSI modelinin Network Layer (Ağ Katmanı) adı verilen 3. katmanını (Layer 3) inceleyeceğiz. Birden fazla protokole sahip diğer OSI katmanlarının aksine, layer 3 çoğunlukla tek bir protokole dayanır — iki ana versiyonu (versions) olan Internet Protocol (IP):

  • IPv4: 32-bit adresler kullanır ve yaklaşık 4.3 milyar benzersiz (unique) IP'yi destekler.
  • IPv6: 128-bit adresler kullanır, çok daha büyük miktarda IP'ye ve artırılmış ağ verimliliğine (network efficiency) olanak tanır.
