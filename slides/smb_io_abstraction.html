"File Sharing"i Daha Fazlası İçin Kullanmak

Windows; bellek akışlarını (memory streams), donanım aygıtlarını ve kimlik doğrulamasını (authentication) File Objects (Dosya Nesneleri) olarak soyutladığından, SMB temel dosya depolamanın çok daha ötesinde işlemler için kullanılır:
IPC$ SHARES Named Pipes & MS-RPC

IPC$ paylaşımına bağlanmak, sanal Named Pipe'lara (dosya olarak dışa açılmış paylaşılan süreçler arası bellek) erişim sağlar.

  • MS-RPC isteklerini ağ üzerinden taşır.
  • PsExec ve rpcclient gibi remote execution araçlarına güç verir.
Inter-Process Communication
PERIPHERALS Network Printers

Windows Print Spooler Service açısından bir ağ yazıcısı (network printer) sadece bir I/O File Destination'dır.

  • SMB, printer objesi için bir handle açar.
  • Diske bir .pdf dosyası kaydetmekle tamamen aynı şekilde ham yazdırma byte'larını stream eder.
Hardware Device I/O Control
SECURITY Credential Testing

Kullanıcı credential bilgilerini doğrulamak veya parola brute-force testleri yapmak SESSION_SETUP aşamasında gerçekleşir.

  • SPNEGO içinde sarmalanmış NTLMv2 veya Kerberos hash'lerini test eder.
  • Fiziksel bir disk paylaşımını mount etmeye gerek kalmadan kullanıcı kimliğini doğrular.
Session Setup Authentication
