Server Message Block (SMB)

SMB Protokolü (Server Message Block), istemcilerin TCP/IP veya diğer katmanlar üzerinde ağ genelindeki dosyalara okuma ve yazma erişimi yapmasını sağlayan bir network file sharing protocol'üdür.
CORE FUNCTION Uzaktan Dosya Erişimi

Uzak paylaşılan dizinleri (ör. \\SERVER\SHARE) yerel sürücü harflerine (ör. Z:) şeffaf biçimde eşleyerek doğrudan okuma ve yazma işlemlerini sağlar.

TRANSPORT TCP/IP Üzerinde Layer 7

Modern ağlarda güvenilir veri iletimi için doğrudan TCP Port 445 (veya legacy NetBIOS over TCP/IP ile Port 139) üzerinde çalışır.

CAPABILITIES Paylaşılan Kaynaklar
  • Dosya İşlemleri: Uzak dosyaları açma, okuma, yazma, lock (kilitleme) ve silme.
  • Cihaz Paylaşımı: Network Printer paylaşımı ve seri port erişimi.
  • IPC İletişimi: Named Pipes aracılığıyla Inter-Process Communication.
