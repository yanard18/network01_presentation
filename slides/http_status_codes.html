HTTP Status Codes Reference

Range Category Meaning & Description Common Examples
1xx Informational Request received, server continuing process. 100 Continue, 101 Switch Protocols
2xx Success Action successfully received, understood, and accepted. 200 OK, 201 Created, 204 No Content
3xx Redirection Further action required by client to complete request. 301 Moved Perm, 302 Found, 304 Not Modified
4xx Client Error Request contains bad syntax or cannot be fulfilled by client. 400 Bad Req, 401 Unauth, 403 Forbidden, 404 Not Found
5xx Server Error Server failed to fulfill an apparently valid client request. 500 Internal Error, 502 Bad Gateway, 503 Unavailable
Status codes are 3-digit integers returned in the HTTP Response Status-Line (e.g., HTTP/1.1 200 OK).
