HTTP Status Codes Referansı

Range Kategori Anlam & Açıklama Yaygın Örnekler
1xx Informational İstek (request) alındı, sunucu işleme devam ediyor. 100 Continue, 101 Switch Protocols
2xx Success İşlem başarıyla alındı, anlaşıldı ve kabul edildi. 200 OK, 201 Created, 204 No Content
3xx Redirection İsteği tamamlamak için istemcinin (client) ek işlem yapması gerekiyor. 301 Moved Perm, 302 Found, 304 Not Modified
4xx Client Error İstek hatalı sözdizimi (syntax) içeriyor veya istemci tarafından yerine getirilemiyor. 400 Bad Req, 401 Unauth, 403 Forbidden, 404 Not Found
5xx Server Error Sunucu (server), geçerli gibi görünen bir client isteğini yerine getiremedi. 500 Internal Error, 502 Bad Gateway, 503 Unavailable
Durum kodları (Status Codes), HTTP Response Status-Line'da döndürülen 3 haneli tam sayılardır (ör. HTTP/1.1 200 OK).
